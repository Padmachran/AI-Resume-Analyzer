# 🤖 AI Resume Analyzer

An AI-powered web application that helps users analyze their resumes, evaluate ATS compatibility, and compare their resumes against specific job descriptions.

The application uses **Google Gemini AI** to generate resume insights and provide practical recommendations for improving a resume.

## 📌 Project Overview

Applying for jobs can be challenging because resumes need to satisfy both recruiters and Applicant Tracking Systems (ATS).

Many resumes contain good experience but fail to effectively communicate relevant skills, keywords, and achievements.

**AI Resume Analyzer** is designed to simplify this process.

The application allows users to:

- Upload a PDF resume
- Extract and analyze resume content
- Generate an ATS score
- Identify strengths and areas for improvement
- Compare a resume with a job description
- Calculate a job-match score
- Identify matching and missing skills
- Identify important keywords
- Get AI-generated recommendations
- Ask career and resume-related questions through the AI assistant

---

## ✨ Features

### 📄 Resume Analysis

Upload a PDF resume and let the AI analyze its contents.

The system evaluates different aspects of the resume and provides:

- ATS score
- Resume strengths
- Areas for improvement
- Skills analysis
- Keyword analysis
- Formatting suggestions
- Actionable recommendations

---

### 📊 ATS Score

The application generates an ATS compatibility score based on the resume content.

This helps users understand how effectively their resume communicates relevant information to automated screening systems.

The score is accompanied by detailed AI-generated feedback rather than being presented as the only measure of resume quality.

---

### 🎯 Job Description Matching

Users can provide a job description along with their resume.

The AI compares the resume against the job requirements and provides:

- Job match score
- Matching skills
- Missing skills
- Matching keywords
- Recommendations for improving the resume for the role

This helps users understand how closely their current resume aligns with a particular position.

---

### 🤖 Gemini AI Analysis

Google Gemini is used as the AI engine for:

- Resume analysis
- ATS evaluation
- Job matching
- Career-related assistance

The AI processes the extracted resume text and generates structured, practical feedback.

---

### 💬 AI Career Assistant

The backend also includes an AI chat endpoint designed to answer questions related to:

- Resume writing
- ATS optimization
- Job applications
- Resume keywords
- Technical skills
- Soft skills
- Interview preparation
- Career development

The chatbot backend is implemented through the FastAPI API.
